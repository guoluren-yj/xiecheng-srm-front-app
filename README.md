### 服务作用

- 甄云srm产品移动子应用服务，提供srm端业务处理能力，当前工程packages下包含各个套件子服务

### 独立构建
- packages下为所有移动端微服务，每个微服务可独立运行、打包，具体操作参考每个微服务下的说明文档

### 统一构建
- 当前工程提供了build.sh，统一构建所有的微服务，执行sh build.sh可进行构建。构建完成后每个微服务dist目录下产生构建生成的包，
将所有的构建的包部署至服务器同一个文件夹内，将文件夹作为根路径nginx代理出去即可。若代理成功访问
https://xxx.xxx.xxx/appPlat/#/public/PaymentResult 能成功载入界面且调用接口为对应后端
网关地址，则部署完成
